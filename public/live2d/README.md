# Live2D runtime assets

This directory intentionally does not bundle model files or `live2dcubismcore.min.js`.

Place Cubism Core at:

`public/live2d/live2dcubismcore.min.js`

Place models using the same paths configured in `src/live2d/models.js`, for example:

`public/live2d/rice/Rice.model3.json`

Copying the original character assets from `metersphere-control-panel` is deliberately left as an explicit local action because those files are large and may have separate redistribution terms from this repository's source code.
